Server connection

Point the console at your on-premises PDP gateway.

The console port of the gateway (443 by default), not the agent port 8443.

Pin the gateway CA so the app trusts only your server. Accepted formats:

  • the hex sha256 of the CA certificate DER, upper or lower case, colons allowed (AB:CD:… as printed by openssl x509 -fingerprint -sha256). The console shows it as CA fingerprint (ca_sha256) when you create an enrolment token; or compute it with openssl x509 -in ca.pem -outform der | sha256sum (ca.pem is served at /dl/ca.pem);
  • an sha256/<base64> pin of the CA's (or the server certificate's) SubjectPublicKeyInfo.

The server certificate must be signed by the pinned CA and valid for the gateway hostname. Leave blank to trust only localhost.
